# Mobile notifications (MOB-06)

Notifications are routing entries: `/notifications/:id` marks read (canonical read state) and redirects to the record after re-reading the record in the reader's own context, so a notification never grants access. Attention items are conditions that leave when the condition does. MOB-06 adds no mobile read state.

Push readiness: a push payload should carry the notification id or a canonical route; the route performs authentication and authorisation. Native push is MOB-10.
