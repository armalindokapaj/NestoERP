# List capability manifest (AUD-08)

Every operational list in NESTO, what it may show and do, and who owns its
query (AUD-08 §2, DT-01). `tests/unit/tables/list-manifest.test.ts` fails when
a `listId="…"` used in `components/**` or `app/**` has no row here, or when a
row does not have exactly the twelve columns below.

This file is the reference for the UI and for tests; it does not grant
anything. The server's query parsers, where-builders, DTO redaction and export
routes stay authoritative (AUD-08 §2 "server validation remaining
authoritative").

## Vocabulary

- **List ID** — `<module>.<list>` (`finance.invoices`, `projects.units`). The
  same id is passed to `DataTable listId` and keys local column preferences.
  Lists that are not `DataTable` consumers (custom tables, nested project and
  record lists) still get a row.
- **Route** — the page path; `[param]` segments as in `app/`.
- **Query owner (file)** — the parser/where-builder that page, API, count,
  summary and export share (DT-02).
- **Scopes & sections** — the authenticated scope (Company, Group, Project,
  own records) and each section's imposed restriction (Mine, Open, Archived…).
- **Search fields** — the fields a search term matches (case-insensitive
  contains unless stated).
- **Filters (semantics)** — each filter key; multi-value is OR within a filter,
  AND across filters unless stated; date ranges state inclusive/exclusive ends
  and date-only vs timestamp.
- **Sort keys (default; nulls; tie-breaker)** — the allowlisted `sort` values,
  the default in **bold**, null placement per nullable key (`nulls last` /
  `nulls first` / `n/a`), and the unique tie-breaker (`withTieBreaker`, `id asc`
  unless stated).
- **Page limit** — default / ceiling, and offered page sizes when a
  Rows-per-page control exists.
- **Columns (mandatory / default-hidden)** — column ids; mandatory ones marked
  `!`, default-hidden ones marked `~`. `—` where the list has no Columns control.
- **Row & bulk actions** — row actions; bulk actions, or **not supported**.
  No list had a selection-based bulk action at the AUD-08 survey.
- **Export (modes; schema; limits)** — **not supported**, or the route, its
  scope modes (All matching / Selected / Current page), the schema ("Standard
  columns"), and the enforced row / byte / duration limits.
- **Tests** — the test files that cover the row (DT-xx ids).

A capability that does not exist is written **not supported**, and its control
is omitted from the page (AUD-08 §2).
